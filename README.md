# 40 CFR Part 1065 local chatbot

Local web app that answers questions from a copy of **40 CFR Part 1065 (Engine-Testing Procedures)** stored in this folder. The regulation text, embeddings, and chat requests stay on this computer. Answers are generated by **Ollama on localhost**.

This is a research aid, not legal advice. eCFR is authoritative but unofficial. Keep Cursor in private mode if you type proprietary test details.

Publishing or deploying this app outside this computer needs your approval first.

## What you need

- Python 3.11 or newer
- [Ollama](https://ollama.com) running locally
- A local model, in order of preference: `llama3.1:8b`, or `llama3.2:3b` on a lighter CPU

## Setup

From this project folder:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
ollama pull llama3.1:8b
python -m app.ingest
python -m uvicorn app.main:app --host 127.0.0.1 --port 8000
```

Then open `http://127.0.0.1:8000`.

## Desktop exe

Double-click `1065Chatbot.exe` in this folder. It starts the local server, opens the chatbot in your browser, and stops the server when you close the launcher window. You can copy a **shortcut** to the Desktop; keep the `.exe` in this project folder so it can find `.venv` and `data`. Ollama still needs to be installed and running.

Rebuild the exe after launcher changes:

```powershell
.\.venv\Scripts\python.exe -m pip install pyinstaller
.\.venv\Scripts\python.exe scripts\build_exe.py
```

Ingest uses the public eCFR Versioner API (no API key) once, then reuses `data/ecfr-title40-part1065.xml` until you pass `--refresh`.

```powershell
python -m app.ingest --refresh
```

Optional environment variables:

- `OLLAMA_HOST` (default `http://127.0.0.1:11434`)
- `OLLAMA_MODEL` (otherwise the app picks `llama3.1:8b` or `llama3.2:3b` if installed)

## Runtime

The browser talks only to `127.0.0.1:8000`. The app talks only to the local index (`data/chroma`) and Ollama on localhost. No company or cloud LLM APIs are used.
